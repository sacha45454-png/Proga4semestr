1. Цель работы: освоение сопрограмм и итераторов на примере чисел Фибоначчи.
2. Задание:
   - Реализовать сопрограмму my_genn, возвращающую список n первых чисел Фибоначчи.
   - Реализовать итератор FibonacchiLst, фильтрующий список по числам Фибоначчи.
3. Используемые средства: Python 3.11, стандартная библиотека.
4. Описание реализации:
   - my_genn: декоратор fib_coroutine для инициализации, два yield (приём n и выдача результата).
   - FibonacchiLst: предварительно строит множество чисел Фибоначчи до max(lst), затем в __next__ итерирует и проверяет принадлежность.
5. Тестирование: написаны 8 тестов (3 для my_genn, 5 для FibonacchiLst). Все тесты пройдены (скриншот прилагается).
6. Исходный код: приложен в файле fib_lab.py.
7. Выводы: работа выполнена, получены навыки работы с корутинами и итераторами.
